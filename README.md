# CHESS STUDIO

Шахматное веб-приложение. **Этап 1:** интерактивная доска и полноценная партия против настоящего Stockfish прямо в браузере.

## Что работает

- Игра белыми, чёрными или случайным цветом; пять уровней сложности (Skill Level, глубина и время на ход реально передаются движку).
- Контроль времени: 1+0, 3+2, 5+0, 10+0, 15+10 и без часов. Флаг по времени с учётом недостатка материала у соперника.
- Все правила — через `chess.js`: рокировка, взятие на проходе, превращение с выбором фигуры, шах, мат, пат, недостаток материала, троекратное повторение, правило 50 ходов.
- Ходы кликом, перетаскиванием (мышь и касание) и с клавиатуры (стрелки + Enter/пробел).
- Подсветка легальных ходов, взятий, последнего хода, шаха; подсказка лучшего хода от Stockfish.
- Отмена хода (до вашего последнего), переворот доски, «Начать заново», «Новая партия», сдача — с подтверждением во время идущей партии.

## Настройки (шестерёнка в шапке или Ctrl + ,)

- **Звук:** Sound Effects ON/OFF, громкость, отдельные переключатели для хода, взятия, шаха, окончания партии и победы/поражения, кнопки прослушивания. Звуки синтезируются Web Audio — без файлов и сети.
- **Фигуры:** Classic, Staunton, Modern, Neo, Glass, Marble, Fantasy, Celtic. Glass и Marble — материал (стекло/мрамор), наложенный на силуэт настоящих SVG-фигур.
- **Доска:** Studio, Classic Wood, Walnut, Tournament, Green, Blue, Dark, Ivory, Graphite, Coral и Custom со своими цветами клеток.
- **Отображение:** координаты, подсветка последнего хода, подсказки ходов, подсветка шаха, анимации и их скорость.
- Всё сохраняется локально и восстанавливается после перезапуска; «Reset Settings» сбрасывает с подтверждением.

## Windows-приложение

Desktop-версия — Electron. Интерфейс собирается отдельным клиентским бандлом (`vite.desktop.config.ts`) и
отдаётся из пакета приложения по схеме `app://`, поэтому сервер, браузер и интернет не нужны.
Stockfish — тот же WASM-движок в Web Worker, отдельный бинарник для Windows не требуется.

На Windows (нужен Node.js 20+):

```sh
npm install
npm run desktop:start   # запустить окно приложения без установки
npm run desktop:dist    # release/Chess Studio Setup 1.0.0.exe и release/Chess Studio Portable 1.0.0.exe
```

На Linux/macOS установщик собирается без Wine: `npm run desktop:installer` (NSIS-скрипт `desktop/installer/chess-studio.nsi`).

- Установщик ставит игру в `%LOCALAPPDATA%\Programs\CHESS STUDIO` (без прав администратора), создаёт ярлыки на рабочем столе и в меню «Пуск», регистрирует удаление в «Приложениях».
- Настройки и размер окна хранятся в `%APPDATA%\CHESS STUDIO` и переживают обновления.
- Повторный запуск ярлыка открывает уже запущенное окно. F11 — полноэкранный режим.
- Файлы не подписаны сертификатом: при первом запуске Windows SmartScreen может показать «Подробнее → Выполнить в любом случае».

```sh

```

## Откуда загружается Stockfish

- Используется npm-пакет [`stockfish`](https://github.com/nmrugg/stockfish.js) (Stockfish 19, сборка **lite, single-threaded WASM**).
- Файлы `stockfish-19-lite-single.js` и `.wasm` лежат в `public/stockfish/` и отдаются как статика с того же домена — никаких внешних CDN.
- После обновления пакета выполните `bun run engine:copy`, чтобы скопировать новые файлы из `node_modules/stockfish/bin`.
- Движок работает в Web Worker и общается по протоколу UCI (`src/lib/engine/stockfishEngine.ts`). Если движок не загрузился, приложение показывает ошибку и кнопку перезапуска — фиктивных ходов нет.
- Лицензия Stockfish — GPLv3, текст в `public/stockfish/COPYING.txt`.

## Ограничения

- Lite-сборка использует уменьшенную нейросеть (NNUE) и один поток: она заметно слабее полной версии на максимальном уровне, зато весит ~2 МБ и не требует cross-origin isolation (SharedArrayBuffer).
- Уровни сложности — это настройки Skill Level / глубины / времени, а не откалиброванный рейтинг ELO.
- Партии не сохраняются: перезагрузка страницы начинает всё сначала.
- Нет экспорта PGN, анализа, задач, онлайна, статистики и аккаунтов — это следующие этапы.

## Архитектура

```text
src/lib/chess/      чистая логика: часы, исходы, сложность, UCI, материал (с тестами)
src/lib/engine/     UCI-клиент Stockfish в Web Worker
src/hooks/          React-обёртки: useChessGame (chess.js), useStockfish, useChessClock
src/components/chess/  переиспользуемая доска (будет нужна анализу, задачам, онлайну)
src/features/play/  экран игры против движка: контроллер + UI-панели
src/routes/         маршруты TanStack Router (новые разделы — новые файлы маршрутов)
src/lib/settings/   настройки пользователя: значения по умолчанию, проверка, сохранение (с тестами)
src/lib/sound/      какие звуки играть (с тестами) и их синтез через Web Audio
src/features/settings/  панель настроек и провайдер, общий для веба и desktop
src/desktop/        точка входа интерфейса Windows-приложения
desktop/            Electron (main.cjs), иконки, NSIS-скрипт установщика
```
